# Why use Naughtian Kallisto?

Two use cases it was built for:

- [Serving high-rate-access KV secrets](./serving-kv-secrets.md) — KV secrets at low latency, with
  policy managed by whatever secret control plane you already run.
- [Distributing mTLS certificates and keys](./distributing-mtls-credetials.md) — the same read path,
  for certificates and keys a mesh of services needs.

See also [use-cases.md](./use-cases.md).
