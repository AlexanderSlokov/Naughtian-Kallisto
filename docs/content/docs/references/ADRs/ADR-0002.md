# ADR-0001: Bỏ persistence ở chế độ proxy

Status: Accepted
Date: 2026-08-16

## Bối cảnh

Kallisto proxy cache dữ liệu thuộc sở hữu của upstream...

## Quyết định

Chế độ proxy không ghi gì xuống đĩa...

## Phương án đã cân nhắc và loại bỏ

- Cache xuống đĩa kiểu Kong DP — loại vì kéo lại chuỗi KEK/unseal, và cache ấm sau restart làm secret đã thu hồi sống dậy
- Chỉ lưu danh sách key nóng — loại vì đường dẫn chính là danh mục bí mật

## Hệ quả

Restart là cache lạnh. Chống dồn cục bằng gộp request trùng + rắc ngẫu nhiên TTL.
