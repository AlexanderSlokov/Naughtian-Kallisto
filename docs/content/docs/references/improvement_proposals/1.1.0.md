# Kallisto 1.1.0

## Goals (in this minor release)

- `kallisto_config.yaml` hoặc `.toml`
- Chia tách rõ hai role qua config flag (`role: proxy | control-plane`)
- State machine: Seal trait + Transit backend
- Encryption barrier
- Module storage backend mới với redb (đã có Hexagonal port)

Lưu ý về tên gọi: ADR-0005 (accepted) đã thay khung "Sovereign = kho secret standalone" bằng "controlplane = bộ điều phối fleet", và chốt hai giá trị config là `proxy` và `control-plane`. "Sovereign" và "Hybrid mode" chỉ còn là codename trong tài liệu thiết kế (ADR-0006, ADR-0010), không phải giá trị hợp lệ của `role:`.

## Non-goals (later — đã đưa vào roadmap)

- Raft / clustering cho control plane
- Foca gossip cho Data Plane
- Tương thích Terraform cho Control Plane để provisioning

Vì Raft nằm ngoài phạm vi 1.1.0, ADR-0008 và ADR-0009 chỉ được hiện thực ở phần không phụ thuộc Raft: thay RocksDB bằng `redb` ở single-node, và bổ sung đường báo ngược `fsync` cho hàng đợi Vyukov. Trait `RaftLogStorage` của `openraft` để lại cho 1.2.0.

## Visible changes

- config: thêm `role:`, thành bắt buộc
- breaking: file config cũ không parse được nữa

## Work items

1. Config schema tagged-enum → brief 01, ADR-0003
2. Seal trait → brief 02, ADR-0012 (chưa viết)
3. Barrier + buffer pool → brief 03, ADR-0012 (chưa viết)

ADR-0012 gộp cả Seal trait, encryption barrier và buffer pool vào một quyết định vì chúng là cùng một hệ thống con. Cần viết trước khi bắt đầu work item 2.

## Nghiệm thu

- cargo test --workspace 100% pass rate
- bench-laptop giữ trong 10% của baseline 1.386ms
- validate reject được config sai role

## Khuyến nghị

Làm proxy mode trước, và để chế độ control-plane lại cho tới khi có người dùng thật hỏi xin nó.

Nên làm proxy mode trước vì nó không hy sinh gì cả. Nó là con đường ngắn nhất tới một thứ hoàn chỉnh, và cũng là con đường tới chế độ control-plane. Hơn nữa, ~70% code dùng chung: engine, HTTP, cuckoo table, auth, barrier.

Encryption barrier cần ở cả hai chế độ, chỉ khác chỗ nó bảo vệ: proxy thì bảo vệ RAM, control-plane thì bảo vệ đĩa.

## Sửa đổi so với bản nháp đầu

Ghi lại để giữ provenance:

- `role: sovereign | proxy` → `role: proxy | control-plane`, theo ADR-0005 đã accepted.
- Work item 1 trỏ ADR-0011 → ADR-0003. ADR-0011 là proxy mode, config format là ADR-0003.
- Work item 2 trỏ ADR-0004 → ADR-0012. ADR-0004 là TUI vs WebUI và đang `suspended`.
- Non-goals ghi "Terraform provider" → "tương thích Terraform". ADR-0007 đã loại phương án viết provider riêng.
- Bỏ danh sách Phase 1–5 nhúng trong file này vì nó mâu thuẫn với chính phần Non-goals ở trên (liệt kê Raft log storage, Terraform provider, và WebUI/TUI trong khi cả ba đều là non-goal). Nội dung được chuyển vào roadmap, không mất gì.
